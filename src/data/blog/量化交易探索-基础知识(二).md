价格 10 元的股票一定比 100 元的便宜吗？公司有利润，为什么还可能缺钱？这篇从这两个问题出发，介绍财报和估值指标，再用原文保留的长江电力截图练习读取数据。

基础知识（一）侧重价格与交易，本篇关注公司的经营数据。这里的截图用于练习计算，不能代表当前行情，也不能仅凭几项指标判断是否值得买入。

## 价格与估值，是两个不同的数

均线、MACD 和布林带都可以从价格序列计算出来。它们整理的是价格变化，财报则提供公司经营、资产和现金流的另一组信息。

但价格只是**别人愿意出的钱**，不等于这东西**本身值多少钱**。这两者经常背离：

![价格围绕价值上下波动](@/assets/images/posts/quant-basics-2-fundamentals/01_price_vs_value.png)

公司的内在价值需要估计，无法像行情价格一样直接读取。图中的平滑线只是示意；经营预期、利率和风险变化时，估值也会明显改变。

技术指标整理价格变化，基本面分析研究经营、资产和现金流。两者可以结合，但并非每个策略都必须同时使用，也不能保证结合后就能识别好买点。

下面先从股价和市值的关系看起。

## 一张股票 = 一家公司的所有权切片

先把一个报价拆开看：股价是每股的价格，总股本是发行的股份数量，两者相乘得到总市值。

普通股代表对公司的股权，但不意味着每年的净利润都会按比例分给股东。是否分红还取决于公司决策与约束；股东通常以出资为限承担责任，不会按持股比例替公司偿还所有债务。

![市值 = 股价 × 总股本](@/assets/images/posts/quant-basics-2-fundamentals/02_market_cap.png)

几个关键量的关系：

```
总股本   = 公司一共切成了多少股
股价     = 每一股现在卖多少钱
总市值   = 股价 × 总股本 = 整个公司现在值多少钱
```

例如：某公司股价 20 元、总股本 10 亿股，那么总市值 = 200 亿。这意味着市场认为“整个公司现在值 200 亿”。

这时可以分清两个问题：

- **股价低，不等于估值便宜。** 10 元 × 200 亿股是 2,000 亿市值，100 元 × 5 亿股是 500 亿市值。前者市值更大，但仍需与盈利、资产和增长预期比较，才能讨论估值。
- **股本会变。** 送股（10 送 10）把每股拆成两股，股价砍半但市值不变，这正是基础知识(一) 讲复权时那个“价格跳空”的来源。市值才是不受拆股影响的真实规模。

记住这个换算：**看到股价，先在脑子里乘上股本换成市值**。后面所有估值指标，本质都是“市值”和“公司某个财务数字”之间的比值。

## 钱的账本：财报三张表

要给公司称重，就得看它的账本。上市公司每季度公布**财务报表**，核心是三张表。别被“财务”两个字吓到，每张表其实只回答一个很朴素的问题：

![资产负债表、利润表、现金流量表三者的关系](@/assets/images/posts/quant-basics-2-fundamentals/03_three_statements.png)

**资产负债表，“此刻家底有多少”**

它是某个时间点的**快照**，回答“公司现在有什么、欠什么、净剩多少”：

```
资产   =   负债   +   所有者权益
(有什么)   (欠别人的)   (真正属于股东的)
```

所有者权益是账面资产减去账面负债的余额。它不是清算时股东一定能拿到的金额：资产出售价格、债务清偿顺序和处置成本都可能不同。比较 PE、PB、ROE 时，还要让归母净利润与归母净资产等口径保持一致。

**利润表，“一段时间赚了多少”**

它统计某个季度/年度的经营成果，是一个**层层扣减**的过程：

```
营业收入
  − 成本、费用、税
= 净利润        ← 按会计口径确认的期间损益，不等于现金净流入
```

净利润是后面 PE 指标的分母，也是市场最关注的数字。

**现金流量表，“钱是不是真的进出了”**

现金流量表记录现金及现金等价物的变动，按经营、投资、筹资活动分类。它帮助我们区分“确认了收入”和“收到了钱”。

例如公司赊销 100 元商品，符合收入确认条件后可以记收入，但客户下月才付款。利润与经营现金流此时不同，并不自动意味着造假。若长期差异很大，就要继续查应收账款、存货、预收款和业务扩张情况。

**三张表怎样配合看？** 利润影响留存收益，收付款改变现金和往来款项，资产负债表记录期末状态。分红、增资和其他权益变动也会影响净资产，不能只靠“净利润减分红”解释所有变化。可对照 [SEC 财务报表入门指南](https://www.sec.gov/about/reports-publications/beginners-guide-financial-statements)理解这几类报表各自的范围。

## 贵还是便宜：核心估值指标

有了市值和财务数字，就能算估值指标了。所谓估值指标，本质都是一个比值，**拿市值去除以公司的某个财务数字**，用来跨公司比较“贵不贵”。

### 3.1 PE：市值是利润的多少倍

PE 是最常用的估值指标：

```
PE = 总市值 / 年净利润 = 股价 / 每股收益
```

PE = 20，可以粗略读成“当前市值是所用年度利润的 20 倍”。只有假定利润不变、全部用于回报股东且忽略时间价值时，才勉强像“20 年回本”；现实中不能把 PE 当成回本年限。

![PE 倍数示意；不能据此保证回本年限](@/assets/images/posts/quant-basics-2-fundamentals/04_pe_payback.png)

相同盈利口径下，PE 较低表示每一元利润对应的市场定价更低。接下来还要检查这份利润能否持续：

- **盈利为负时 PE 没有意义。** 亏损公司算出来的 PE 是负数或天文数字，直接失效。
- **跨行业比较要谨慎。** 行业的增长、资本需求和风险不同；同一行业内也要区分会计口径和一次性收益。
- **低 PE 可能来自盈利高点。** 如果下一年的利润大幅下降，原先看似便宜的倍数就失去了参考基础。

### 3.2 PB：市净率：相对家底贵不贵

```
PB = 总市值 / 所有者权益（净资产）= 股价 / 每股净资产
```

PB 比较市值和账面净资产。PB = 1 只表示这两个数相等，不代表公司清算时能按该金额返还股东。

PB 特别适合两类场景：

- **资产负债表较重要的行业**：PB 可以作为观察指标，但仍需检查资产质量、减值和负债。
- **亏损公司**：若净资产为正且有参考意义，可以继续看 PB；持续亏损也可能快速消耗净资产。

**PB < 1**（破净）表面看是“打折买家底”，但同样要警惕：市场愿意给低于净资产的定价，往往是因为它认为这些资产在贬值或赚不到钱。

### 3.3 ROE：利润相对于股东权益的比例

如果只能看一个指标，很多人会选 ROE。因为它直接回答：**股东投进去的钱，每年能生出多少钱。**

```
ROE = 年净利润 / 所有者权益
```

ROE = 20% 表示某个报告期的利润相对于所用净资产口径约为 20%，不等于股价回报 20%，也不等于股东权益一定增长 20%。分红、回购和增资都会改变这个关系。计算时通常使用平均净资产，还要区分加权、摊薄和扣非口径。

ROE 可以**拆成三个因子**（杜邦分析），告诉你这家公司到底靠什么赚钱：

![ROE 的杜邦三因子拆解](@/assets/images/posts/quant-basics-2-fundamentals/05_roe_dupont.png)

```
ROE = 净利率 × 资产周转率 × 权益乘数
      (卖得贵)   (卖得快)     (加杠杆)
```

- **净利率高**（靠卖得贵）：茅台式，每瓶利润厚。
- **周转率高**（靠卖得快）：超市式，单件利润薄但走量。
- **权益乘数高**（靠借钱）：银行/地产式，用杠杆放大收益，但杠杆是双刃剑，行情差时同样放大亏损。

同样是 20% 的 ROE，靠前两者驱动的是“好生意”，主要靠加杠杆撑起来的则要警惕风险。**拆开看 ROE 的来源，比只看它的数值重要得多。**

### 3.4 三个指标怎么配合用

| 指标 | 比的是   | 适合               | 主要陷阱                           |
| ---- | -------- | ------------------ | ---------------------------------- |
| PE   | 赚钱能力 | 盈利稳定的成熟公司 | 亏损失效、跨行业不可比、低 PE 陷阱 |
| PB   | 家底     | 重资产、亏损公司   | 破净未必便宜                       |
| ROE  | 赚钱效率 | 几乎所有公司       | 高杠杆撑起的高 ROE 有风险          |

把三个指标放在一起，是为了提出更具体的问题：利润质量如何？资产是否减值？高 ROE 来自经营效率还是杠杆？单凭“高 ROE + 低 PE”仍不能完成估值判断。

### 3.5 实战：用长江电力把三个指标读活

下面保留原文的长江电力行情截图，用于练习口径核对。截图是历史记录，不是实时数据。

![长江电力行情页：市值 7071 亿、市盈 TTM 19.6](@/assets/images/posts/quant-basics-2-fundamentals/12_changjiang_electric_quote.png)

**第一步，行情页上直接能读到的**：总市值 7071.3 亿、市盈 TTM 19.60（这就是 PE，TTM 表示按最近滚动四个季度的净利润计算）。有了这两个数，就能反推出图上没直接给的净利润：

```
年净利润 ≈ 总市值 / PE = 7071.3 / 19.60 ≈ 361 亿元
```

计算得到约 360.8 亿元，对应的是截图使用的 TTM 盈利口径，并不是对下一年利润的预测。

**第二步，19.6 倍是否合理？** 仅凭截图无法下结论。水电公司的盈利还受来水、电价、设备运行、折旧和融资成本影响。可以继续查历年报告，观察盈利与经营现金流的变化，再讨论估值假设。

**第三步，PB 和 ROE 要去财务页（F10 简况）查**，分时行情页上不显示。翻到 F10 的“最新指标”，长江电力的数据一目了然：

![长江电力 F10 最新指标：PB 3.10、净利率 38.01%、净资产收益率 3.01%（一季报单季）](@/assets/images/posts/quant-basics-2-fundamentals/13_changjiang_f10_indicators.png)

先看 **PB 3.10**。它和股价能对上，图里每股净资产 9.314 元，拿股价一除就是 PB：

```
PB = 股价 / 每股净资产 = 28.90 / 9.314 ≈ 3.10
```

PB 3.10 表示市值约为所用账面净资产的 3.10 倍。为什么存在溢价，还需结合未来盈利、资本成本和风险解释，不能只用一个 ROE 数字反推市场定价原因。

再看截图里的 ROE 3.01%。页面标注“2026 一季报”，应先按该报告期理解，而不能直接与年度 ROE 比较。水电经营有季节性，把一季度简单乘四也不可靠；要查年度报告或口径明确的滚动指标。原文未提供支持“常年 13%～16%”的年度数据表，这里不再沿用该区间。

如果粗略使用同一时点的净资产和同一年度利润，PB、PE、ROE 有 `PB ≈ PE × ROE` 的关系。但实际页面可能混用期末净资产、平均净资产和不同报告期，不能拿一季度 ROE 与 TTM PE 直接相乘。

这张截图可以继续算一个期末口径的权益乘数，但还不足以完成同口径的杜邦拆解：

```
净利率       = 38.01%
期末权益乘数 = 1 / (1 − 57.33%) ≈ 2.34
资产周转率   = 同期营业收入 / 平均总资产（需另查数据）
```

毛利率描述收入扣除营业成本后的比例；净利率还受费用、税费和其他损益影响。净利润也不等于已经收到的现金，不能把“净利率”解释成现金落袋比例。

这段杜邦计算只能帮助拆解截图中的数字。若使用期末资产负债率近似权益乘数，却拿平均口径的 ROE 来对应，结果还会有口径误差。是否高度依赖杠杆，需要结合有息负债、利息支出和偿债安排判断。

**第四步，查看历史估值的展示方式。** 同一公司的不同时期也可能有资产重组、盈利结构或会计口径变化。下面的估值通道可以提供比较线索，先确认它画的是什么：

![长江电力 PE 通道截图：图中标注多个估值倍数](@/assets/images/posts/quant-basics-2-fundamentals/14_changjiang_pe_band.png)

图里标出的倍数区间可以辅助观察相对位置，但绘图轨道不一定等于实际历史估值的最小值和最大值。还需要核对软件的算法、日期和盈利口径，不能据此直接认定当前“不便宜但未高估”。

读完这几张图，能确认的是市值、PE、PB 如何相互换算，以及不同报告期的 ROE 不能混着比较。关于经营稳定性、分红可持续性和估值高低，还需要年度报告与明确假设来支持。

> 截图用于说明读数和计算，数据时点以图中标注为准。页面的报价日期、财报期间和指标更新日期可能不同，记录时最好分别保存。

## 买什么：价值 vs 成长两种哲学

基础知识(一) 的第四层讲过技术面的两大流派，趋势跟踪 vs 均值回归。基本面选股同样有一对镜像哲学：**价值派 vs 成长派**。

![价值股与成长股的盈利-股价路径对比](@/assets/images/posts/quant-basics-2-fundamentals/06_value_vs_growth.png)

**价值派（Value）**

- **信念**：好公司被市场错杀了，价格终会回归价值。
- **找什么**：低 PE、低 PB、高股息，被低估的成熟公司（银行、公用事业、周期股底部）。
- **赚什么钱**：**估值修复**，买入时便宜，市场纠错后估值抬升。
- **最怕**：**价值陷阱**，便宜是因为它真的要衰退，估值不但不修复反而继续跌。

**成长派（Growth）**

- **信念**：优秀的公司会持续高速成长，现在贵一点无所谓，未来会赚回来。
- **找什么**：高营收/利润增速、高 ROE、大赛道（科技、新能源、创新药）。
- **赚什么钱**：**盈利成长**，就算估值不变，利润翻倍股价也能翻倍。
- **最怕**：**成长证伪**，一旦增速不及预期，戴维斯双杀（利润和估值同时下杀），跌起来极猛。

价值与成长可以在同一家公司上同时体现，也不能简单对应成均值回归与趋势跟踪。前者讨论买入价格与未来经营的关系，后者讨论价格信号；它们处在不同的分析层面。

## 大盘怎么动：市场结构

个股不是孤立的。一只股票的涨跌，很大一部分由它所属的**板块**和当前的**市场风格**决定。理解市场结构，才能明白“为什么我选的公司基本面很好，却还是不涨”。

### 5.1 板块轮动：钱在行业间流动

不同行业对需求、通胀和利率变化的反应不同，因此可以观察行业之间的相对表现。下面的投资时钟用来整理经济状态与资产的关系，不代表市场会按固定顺序运行：

![美林时钟：经济周期四阶段与领涨板块](@/assets/images/posts/quant-basics-2-fundamentals/07_sector_rotation.png)

这就是经典的**美林时钟**思路：经济从复苏→过热→滞胀→衰退循环，每个阶段占优的资产和板块不同，复苏期看周期成长股，过热期看资源商品，衰退期资金躲进防御性板块（公用事业、必需消费）。

板块表现可以作为比较背景，但强弱排名本身不能说明某只股票下一步的方向。若要使用轮动规则，应事先定义可计算的条件，再检验。

### 5.2 风格切换：大小盘、价值成长

除了行业，市场还有一层更宏观的**风格**维度，主要是两组对立：

- **大盘 vs 小盘**：资金偏好大市值蓝筹，还是小市值成长。
- **价值 vs 成长**：钱流向低估值蓝筹，还是高增长赛道。

![大盘/小盘、价值/成长的风格相对强弱](@/assets/images/posts/quant-basics-2-fundamentals/08_style_rotation.png)

不同阶段，大盘、小盘、价值和成长的相对收益可能变化。回测时应查看策略长期偏向哪些风格，避免把承担某种风格风险的收益全部算作选股能力。

## 怎么量化选股：把基本面做成因子

前面几层是“人肉”看基本面。但如果要像量化系列一贯的思路那样**系统化、可回测**，就得把基本面指标变成**因子（Factor）**。

**什么是因子**：一个能给全市场股票**打分排序**的量化指标。PE、PB、ROE、营收增速……每一个都可以是一个因子。核心假设是：**按某个因子排序，排在前面的一组股票，长期收益会系统性地跑赢排在后面的**。

例如检验低 PE 因子，可以先剔除分母不适用的样本，再比较不同 PE 分组在未来一个月的收益。多空组合在研究中便于观察差异，实盘还要处理融券可得性、成本和其他约束。

**多因子选股**就是把多个因子的打分**加权组合**，层层筛选：

![多因子选股漏斗：从全市场层层筛到组合](@/assets/images/posts/quant-basics-2-fundamentals/09_factor_funnel.png)

一个典型的漏斗：

```
全市场约 5000 只
  → 剔除 ST、停牌、上市不满一年（清洗，呼应(一) 的数据清洗）
  → ROE > 15%          （盈利质量因子）
  → 0 < PE < 30        （估值因子，且过滤亏损）
  → 营收增速 > 20%      （成长因子）
  → 按综合得分排序，取前 30 只等权买入
```

这个漏斗把文字条件变成了可计算规则。阈值只是一组研究示例；实际检验还要处理行业差异、缺失值、财报公告时间与交易成本。

> 需要清醒的是：**因子会失效**。历史上有效的因子（比如小市值因子在 A 股早年极其强势），随着越来越多人使用会被“抹平”，甚至反转。这和(一) 第七层讲的“过拟合”是同一类风险，别把过去有效的因子当成永恒真理。

## 会踩什么坑：基本面陷阱

财报数据有明确出处，但仍会受报告口径、一次性损益和披露时间影响。下面看三个容易误读的情形。

### 7.1 价值陷阱：便宜是有原因的

假设一家公司当前 PE 为 5，但随后利润快速下滑。原来的低倍数，就未必意味着买入价格便宜：

![价值陷阱：低 PE 但盈利与股价一起下滑](@/assets/images/posts/quant-basics-2-fundamentals/10_value_trap.png)

原因是：**PE 低不代表便宜，可能是市场提前反映了盈利的衰退**。分子（市值）跌，是因为市场预见到分母（未来利润）会跌得更多。夕阳行业、被技术颠覆的公司、周期顶点的强周期股，都容易呈现“低 PE”的假象。**静态的低估值 ≠ 便宜，要看盈利的趋势**。

### 7.2 周期股：低倍数可能对应盈利高点

周期行业的盈利可能大幅波动。利润接近高点时，静态 PE 看上去很低；盈利下降时，PE 又可能升高甚至失效。因此要观察周期位置，不能只按 PE 排序。

但“低 PE 必然见顶、高 PE 必然见底”同样不成立。供需、产能和成本变化需要独立研究，PE 不能单独充当周期股的买卖信号。

### 7.3 财务造假：利润和现金流的背离

回到第二层强调的现金流量表。可以从对比两项数据开始检查：**净利润**和**经营活动现金流**：

- 一家健康的公司，长期看两者应该大致同向、匹配。
- 如果**净利润连年增长、经营现金流却持续为负或远低于利润**，说明“赚的都是纸面利润，没收到真钱”，可能是激进赊销、甚至虚构收入。

应收账款增速、存货积压和毛利率异常都可以作为进一步核查的线索。现金流量表也可能被操纵，不能把它当成天然真实的校验器。

## 基本面筛选与技术信号怎样一起检验

到这里，两篇基础知识分别覆盖了不同的观察角度：

- **基础知识(一)** = 技术面：价格怎么动、指标怎么用、风险怎么控、策略怎么评估。
- **基础知识(二)** = 基本面：公司值多少、财报怎么读、怎么选出好公司。

它们不是二选一，而是**回答两个不同的问题**：

可以先用财务条件形成候选池，再用价格条件生成信号。两组条件都要写清楚，并分别检验。

![基本面选股 × 技术面择时的四象限](@/assets/images/posts/quant-basics-2-fundamentals/11_combine_quadrant.png)

下图是一种组织研究问题的示意。“好公司”和“好时机”都需要可检验的定义，不能把右上角直接当成可以买入的结论。

- **基本面做筛选（选股）**：先用 ROE、估值、成长等因子，从全市场筛出一批基本面过硬的好公司，进入自选池。
- **技术面做择时（选时）**：在这批好公司里，用(一) 的趋势/突破信号，等它进入强势形态、站上关键均线时再买入；用 ATR 和事先设定的风险预算估算仓位，再模拟无法按计划止损的情况。

加入技术筛选后，可能避开部分下跌阶段，也可能错过上涨或增加交易成本。要比较加入规则前后的样本外结果，才能知道这种组合是否有帮助。

## 下一步

掌握读数方法后，可以选一份已披露的年度报告，自己核对一次归母利润、净资产和现金流。代码练习可以从以下问题开始：

1. **单因子回测**：用 AKShare 拉财务数据，构建低 PE / 高 ROE 单因子组合，验证在 A 股是否真有超额收益。
2. **多因子合成**：把估值、质量、成长、动量因子标准化后加权打分，做分层回测。
3. **基本面 + 技术面策略**：基本面因子选股池 + 海龟突破择时，看能否改善(一) 里纯趋势策略在 A 股偏低的 Sharpe。
